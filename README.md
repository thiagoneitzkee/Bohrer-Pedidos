# Bohrer Pedidos 3.0

MVP completo de sistema de pedidos online, feito em HTML, CSS e JavaScript puro e preparado para GitHub Pages.

## Recursos
- Cardápio responsivo
- Busca e categorias
- Carrinho e checkout
- Delivery/retirada
- Cupom BOHRER10
- Histórico e acompanhamento do pedido
- Envio do pedido para WhatsApp
- Painel administrativo com login de demonstração
- Kanban de pedidos
- CRUD de produtos
- Configurações do restaurante
- Relatório/resumo de vendas
- Persistência via localStorage
- Sincronização entre abas do navegador via evento `storage`

## Acesso de demonstração
Usuário: `admin`
Senha: `bohrer123`

## GitHub Pages
Envie `index.html` e a pasta `assets` para a raiz do repositório. Em Settings > Pages, selecione `main` e `/ (root)`.

## Importante para produção
Esta versão é um MVP sem servidor. Para uso real, a próxima etapa é trocar o localStorage por backend/banco de dados, autenticação segura e integração oficial de WhatsApp/pagamentos.
